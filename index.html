Project Overview

What Fit-Balance does

Fit-Balance supports users in organizing workout routines and managing nutrition goals. It helps users monitor calorie intake, set fitness objectives, and follow routines suited for weight loss, muscle gain, or balanced wellness.

🏋️

Workout Guidance

Organizes routines and workout screens so users can follow fitness activities more clearly.

🥗

Nutrition Tracking

Supports calorie awareness for deficit, surplus, or maintenance-based fitness goals.

🎯

Goal Setting

Includes improved goal choices such as Muscle Gain, Fat Loss, Push/Pull, and Full-Body routines.

Evaluation Scope

How the prototype was evaluated

The website documents the design changes made after heuristic evaluation and prepares the prototype for usability testing with actual respondents.

01

Prototype Review

The current Fit-Balance screens were reviewed to identify problems in navigation, feedback, consistency, and user control.

02

Heuristic Evaluation

Each screen was assessed using Nielsen’s usability heuristics to locate specific interface issues and improvement opportunities.

03

Recommendations Applied

The goal screen and workout screens were refined based on the evaluation findings, especially issues related to user control and freedom.

04

Usability Testing

The improved prototype is prepared for respondent testing using consent forms, respondent profiles, SUS, and open-ended feedback.
