FIT-BALANCE WEB REPORTING SITE

This folder is ready to deploy as a static website through Vercel, Netlify, or GitHub Pages.

Files:
- index.html: Home page
- data-gathering.html: Consent form, respondent profile, instruments, and testing tasks
- heuristic-evaluation.html: Heuristic evaluation findings and issue table
- usability-testing.html: Usability testing process and SUS items
- results.html: Results, discussion, evidence gallery
- recommendations.html: Design improvements and conclusion
- walkthrough.html: Embedded Figma prototype and demo guide
- styles.css: Website design
- script.js: Mobile menu, reveal animation, heuristic issue filter
- assets/: Placeholder logo/photos/screenshots
- docs/: Add your PDF files here

Before final submission:
1. Replace member names, roles, and photos.
2. Replace placeholders with actual prototype screenshots and testing photos.
3. Add your completed documents in the docs folder:
   - consent-form.pdf
   - respondent-profile.pdf
   - sus-questionnaire.pdf
   - open-ended-feedback.pdf
   - heuristic-evaluation-workbook.pdf
4. Update actual respondent count and SUS results on results.html.
5. Deploy the folder on Vercel.
