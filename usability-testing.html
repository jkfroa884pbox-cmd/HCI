Usability Testing

Testing plan with actual respondents

After applying recommendations from the heuristic evaluation, the improved Fit-Balance prototype is prepared for usability testing using task-based review, SUS, and open-ended feedback.

MethodTask-Based Test

Respondents explore key screens and complete simple prototype tasks.

InstrumentSUS + Feedback

Quantitative ratings are supported by qualitative comments.

Duration10–15 mins

Short session designed to avoid respondent fatigue.

Testing Flow

Step-by-step usability testing procedure

1

Orientation

Briefly explain the purpose of the evaluation and clarify that the prototype, not the respondent, is being tested.

2

Consent

Provide the consent form and explain voluntary participation, confidentiality, and estimated session time.

3

Task Performance

Ask respondents to explore the dashboard, choose a goal, review workouts, and inspect nutrition-related features.

4

Survey

Let respondents answer the SUS questionnaire and open-ended feedback questions.

5

Documentation

Collect screenshots, photos, forms, and notes that can be included as evidence in the web report.

SUS Instrument

System Usability Scale items

Attach SUS PDF
  1. I think that I would like to use this system frequently.
  2. I found the system unnecessarily complex.
  3. I thought the system was easy to use.
  4. I think that I would need the support of a technical person to be able to use this system.
  5. I found the various functions in this system were well integrated.
  6. I thought there was too much inconsistency in this system.
  7. I would imagine that most people would learn to use this system very quickly.
  8. I found the system very cumbersome to use.
  9. I felt very confident using the system.
  10. I needed to learn a lot of things before I could get going with this system.
Open-Ended Questions

Qualitative feedback prompts

What part of Fit-Balance was easiest to understand?

Identifies interface strengths and features that should be preserved.

What part felt confusing or difficult?

Reveals navigation, wording, layout, or interaction problems.

What improvement would make the system more useful?

Collects user-centered suggestions for design refinements.

Would you use this for fitness/nutrition management? Why?

Checks perceived usefulness and user acceptance.
