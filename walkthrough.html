Walkthrough Script Guide

What to explain during the demo

1. Introduce the system

Fit-Balance is designed to help users manage fitness goals, workout routines, and nutrition-related progress in one prototype.

2. Show the goal screen

Explain that the goal screen was added based on evaluation findings to make the user journey more guided and easier to understand.

3. Show workout flow

Discuss how workout screens were reviewed to improve user control, especially for changing or reviewing selected routines.

4. Connect to usability testing

Explain that the updated prototype will be tested with respondents through SUS and open-ended feedback.
